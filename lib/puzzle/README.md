# Rätselgitter

Gemeinsame Helfer für die Logikrätsel der Welle 3.

- `grid.js`: `at`, `index`, `around` (Nachbarn, optional diagonal).
- `grid.css`: `.pz` legt ein quadratisches Tipp-Gitter.

Jedes Spiel bringt die Regeln selbst mit und nutzt die Brett-Hülle `lib/board/kit.js` für Menü, Anleitung und Sprache.
