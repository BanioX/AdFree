# Wortlisten

`de.js` ist die deutsche Liste (aus den Wortrate-Listen, plus kurze und lange Ergänzungen).
`en.js` ist eine eigene englische Liste, keine Übersetzung.

`lexicon.js` liefert `hasWord`, `wordsOf` und `normalize` in der aktuellen Sprache.
`spell.js` sucht Wörter zu einem Buchstabenrad (`makeWheel`).
